1. 通知中心系统 (NotificationCenter)
   ✓ 支持 6 大推送渠道:
     - WebSocket (实时推送, T+0s)
     - App Push (FCM/VAPID, T+1s)
     - Email (HTML 模板, T+30s)
     - SMS (腾讯云/阿里云, T+60s)
     - DingTalk (钉钉私聊)
     - WeChat Work (企业微信)
   
   ✓ 智能路由系统:
     - 关键 (CRITICAL): 全渠道推送
     - 高 (HIGH): WebSocket + App + Email
     - 普通 (NORMAL): WebSocket + Email
     - 低 (LOW): Email only
   
   ✓ 核心功能:
     - 用户偏好检查
     - 频率控制 (防轰炸, 30s 内同类型最多 1 条)
     - 通知记录持久化
     - 并行推送处理

2. 异步队列系统 (NotificationQueue)
   ✓ Redis 异步处理
   ✓ 3 次重试机制 (5s → 10s → 20s 递增退避)
   ✓ 死信队列 (DLQ) 失败处理
   ✓ 后台处理器

3. 模板管理系统 (NotificationTemplate)
   ✓ 6 个预建模板:
     - message_received (新消息)
     - friend_request (好友请求)
     - group_invite (群邀请)
     - moment_like (朋友圈点赞)
     - moment_comment (朋友圈评论)
     - payment_received (收款通知)
   
   ✓ 多语言支持 (zh-CN, en-US)
   ✓ 变量替换引擎
   ✓ 自定义模板存储

4. 多渠道服务模块
   ✓ Email Service (Nodemailer)
   ✓ SMS Service (腾讯云/阿里云双支持)
   ✓ DingTalk Service (钉钉 SDK)

   ✓ POST   /api/notifications/device-token - 注册设备
   ✓ GET    /api/notifications/template/:type - 获取模板
   ✓ POST   /api/notifications/queue - 异步入队
