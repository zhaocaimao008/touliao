## 🚨 故障响应

### 如果看到红色告警 🔴

**立即行动** (< 1 分钟):

1. **暂停其他操作** - 专注于故障
2. **查看具体指标** - 在监控屏幕(屏幕2)查看
3. **判断严重程度** - 是否需要回滚
4. **执行回滚** - 在屏幕3运行回滚脚本

### 常见故障处理

**故障 1: 延迟突增 (> 500ms)**
```
原因: 可能是数据库连接泄漏或缓存失效
处理: 立即回滚 (Level 1 or 2)
```

**故障 2: 错误率上升 (> 1%)**
```
原因: 可能是新代码有 Bug
处理: 查看错误日志，立即回滚
```

**故障 3: Pod 无法启动**
```
原因: 可能是资源不足或镜像有问题
处理: 检查日志，修复问题，重新部署
```
