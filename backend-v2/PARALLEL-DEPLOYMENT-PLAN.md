## 并行部署流程

### 1️⃣ 灰度部署 (并行进行)

**目标**: 5% → 50% → 100%（快速验证）

**每个阶段耗时**: 20-30 分钟

```bash
Stage 1: 5% 灰度 (Region A - 单区域)
├─ 验证项: 响应时间、错误率、用户反馈
├─ 通过标准: 延迟 <200ms, 错误率 <0.1%, P95 <500ms
└─ 失败策略: 立即回滚

Stage 2: 50% 灰度 (Region A/B - 双区域)
├─ 验证项: 跨域通信、缓存一致性、消息可靠性
├─ 通过标准: 所有P1-P4优化指标达成
└─ 失败策略: 快速回滚到5%

Stage 3: 100% 灰度 (All Regions - 全球)
├─ 验证项: 全球延迟、CDN 智能路由、故障转移
├─ 通过标准: 全球延迟 <150ms, 可用性 99.999%
└─ 失败策略: 立即全部回滚
```

### 2️⃣ 全量部署 (并行准备)

**目标**: 灰度通过后立即全量推进

```bash
T+1h: 灰度 5% 验证通过 → 全量开始推进

Parallel Phase 1: 全量 5%
├─ 覆盖: 5% 生产流量 (50万+ DAU)
├─ 监控: 密集采样 (10s 间隔)
└─ 成功指标: 与灰度一致

Parallel Phase 2: 全量 50%
├─ 覆盖: 50% 生产流量 (100万+ DAU)
├─ 监控: 标准采样 (30s 间隔)
└─ 成功指标: 无P1级事件

Parallel Phase 3: 全量 100%
├─ 覆盖: 100% 生产流量 (200万+ DAU)
├─ 监控: 常规采样 (1min 间隔)
└─ 成功指标: SLA 达成

灰度 ────────────────────────────────────────────
5%  50%  100%  ↓ (验证完成，归并)

全量 ────────────────────────────────────────────
     5%   50%   100% ✅ (上线完成)
```

## 🔧 部署脚本

### 启动灰度 + 全量并行部署

```bash
#!/bin/bash

set -e

echo "🚀 启动灰度 + 全量并行部署..."

# Phase 0: 准备
echo "📋 准备阶段..."
./scripts/pre-deployment-check.sh

# Phase 1: 灰度 5% + 全量准备 (并行)
echo "🔵 灰度 5% + 全量准备..."
(
  ./scripts/deploy-canary-5percent.sh &
  ./scripts/prepare-full-deployment.sh &
  wait
) || exit 1

# Phase 2: 灰度验证 (20 分钟)
echo "⏱️  灰度验证中 (20 分钟)..."
sleep 20m

# Phase 3: 灰度验证通过 → 全量 5% + 灰度 50% (并行)
if ./scripts/validate-canary.sh; then
  echo "✅ 灰度 5% 验证通过！启动全量部署..."
  (
    ./scripts/deploy-full-5percent.sh &
    ./scripts/deploy-canary-50percent.sh &
    wait
  ) || exit 1
else
  echo "❌ 灰度 5% 验证失败，回滚..."
  ./scripts/rollback-canary.sh
  exit 1
fi

# Phase 4: 监控与进度 (30 分钟)
echo "📊 监控灰度 50% + 全量 5%..."
sleep 30m

# Phase 5: 灰度 100% + 全量 50% (并行)
if ./scripts/validate-canary-50percent.sh; then
  echo "✅ 灰度 50% 验证通过！推进全量..."
  (
    ./scripts/deploy-canary-100percent.sh &
    ./scripts/deploy-full-50percent.sh &
    wait
  ) || exit 1
else
  echo "❌ 灰度 50% 验证失败，回滚..."
  ./scripts/rollback-canary-50percent.sh
  exit 1
fi

# Phase 6: 最终冲刺 (30 分钟)
echo "📊 监控灰度 100% + 全量 50%..."
sleep 30m

# Phase 7: 全量 100%
if ./scripts/validate-full-50percent.sh; then
  echo "✅ 全量 50% 验证通过！推进 100%..."
  ./scripts/deploy-full-100percent.sh || exit 1
else
  echo "❌ 全量 50% 验证失败，回滚..."
  ./scripts/rollback-full-50percent.sh
  exit 1
fi

# Phase 8: 最终验证 (30 分钟)
echo "📊 最终验证中..."
sleep 30m

if ./scripts/validate-full-100percent.sh; then
  echo "🎉 全量上线成功！"
  ./scripts/finalize-deployment.sh
else
  echo "❌ 全量 100% 验证失败，回滚..."
  ./scripts/rollback-full-100percent.sh
  exit 1
fi

echo "✅ 部署完成！总耗时: ~2.5 小时"
```
