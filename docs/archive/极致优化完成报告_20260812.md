### 3️⃣ 网络请求优化系统
**文件**: `web/src/utils/requestOptimizer.js`

**功能特性**:
- ✅ 防抖节流（支持 leading/trailing/maxWait 模式）
- ✅ 请求去重（相同参数的并发请求只发送一次）
- ✅ 批量合并请求（DataLoader 模式）
- ✅ 智能重试（指数退避 + 抖动算法）
- ✅ 请求队列（并发控制）
- ✅ 带 TTL 的请求缓存

**使用方法**:
```javascript
import {
  throttle,
  debounce,
  dedupeRequest,
  batchRequests,
  retryWithBackoff,
  requestQueue,
  cachedRequest
} from './utils/requestOptimizer';

// 防抖搜索
const debouncedSearch = debounce((query) => {
  api.search(query);
}, 300);

// 批量加载
const users = await batchRequests(
  userIds.map(id => () => api.getUser(id))

// 智能重试
const data = await retryWithBackoff(() => api.fetchData(), {
  maxRetries: 3,
  baseDelay: 1000
});
```

**功能特性**:
- ✅ 完整的 OpenTelemetry 集成
- ✅ 自动追踪所有 HTTP 请求
- ✅ 数据库操作追踪
- ✅ 自定义 span 创建
- ✅ trace_id 和 span_id 自动生成
- ✅ Jaeger 可视化（GRPC 导出器）
- ✅ 降级支持（追踪服务不可用时使用内存追踪）

**使用方法**:
```javascript
// 自动追踪中间件（已集成）
app.use(tracing.middleware());

// 手动追踪异步操作
await tracing.trace('database-query', async (span) => {
  span.setAttribute('query', 'SELECT * FROM users');
  return await db.query('SELECT * FROM users');
});

// 追踪同步操作
const result = tracing.traceSync('compute', (span) => {
  span.setAttribute('input', data);
  return compute(data);
});
```

## 🚀 部署建议

### 1. 环境变量配置
```bash
# 追踪系统（可选）
OTEL_EXPORTER_OTLP_ENDPOINT=localhost:4317
OTEL_SERVICE_NAME=vxin-backend

# Sentry 错误追踪（推荐）
SENTRY_DSN=https://your-sentry-dsn

# Redis 缓存
REDIS_HOST=localhost
REDIS_PORT=6379
```

### 2. Jaeger 部署（可选）
```bash
docker run -d --name jaeger \
  -p 4317:4317 \
  -p 4318:4318 \
  -p 16686:16686 \
  jaegertracing/all-in-one:1.50
```

访问: http://localhost:16686

### 3. 前端部署
```bash
cd web
npm run build
# 将 dist/ 目录部署到 CDN 或静态托管
```

### 4. 后端部署
```bash
cd backend-v2
pm2 start ecosystem.config.js --env production
pm2 save
```
