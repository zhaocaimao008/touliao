### 2️⃣ 集成 Redis 缓存（10 分钟）

**方式 A：自动集成脚本（推荐）**

```bash
cd /root/v信/backend-v2

# 创建集成脚本
cat > integrate-cache.sh << 'SCRIPT'
#!/bin/bash

# 在好友列表路由中集成缓存
sed -i '/router.get.*\/contacts/,/});/ {
  /async (req, res)/a\
  const { friendsCache } = require("../utils/redisCache");\
  \
  // 先查缓存\
  let friends = await friendsCache.get(req.user.userId);\
  if (friends) {\
    return res.json(friends);\
  }
}' src/routes/contacts.js

echo "✅ 缓存集成完成"
SCRIPT

chmod +x integrate-cache.sh
./integrate-cache.sh
```

**方式 B：手动集成**

编辑 `/root/v信/backend-v2/src/routes/contacts.js`：

```javascript
const { friendsCache, onlineStatusCache } = require('../utils/redisCache');

// 好友列表接口
router.get('/contacts', auth, async (req, res) => {
  try {
    // 先查缓存
    let friends = await friendsCache.get(req.user.userId);
    
    if (!friends) {
      // 缓存未命中，查数据库
      friends = await db.prepare(`
        SELECT u.id, u.username, u.avatar, u.nickname, f.status
        FROM friends f
        JOIN users u ON f.friend_id = u.id
        WHERE f.user_id = ?
      `).all(req.user.userId);
      
      // 写入缓存（30 分钟）
      await friendsCache.set(req.user.userId, friends);
    }
    
    // 批量获取在线状态
    const userIds = friends.map(f => f.id);
    const onlineStatus = await onlineStatusCache.batchGetOnline(userIds);
    
    // 合并在线状态
    friends.forEach(friend => {
      friend.online = !!onlineStatus[friend.id];
    });
    
    res.json(friends);
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});
```

**重启服务：**

```bash
pm2 restart vxin-server-v2
pm2 logs vxin-server-v2 --lines 50
```

### 3️⃣ 配置 GitHub Actions（15 分钟）

**步骤：**

1. **生成 SSH 密钥（如果没有）：**

```bash
ssh-keygen -t ed25519 -C "github-actions@dipsin.com" -f ~/.ssh/github_actions
cat ~/.ssh/github_actions.pub >> ~/.ssh/authorized_keys
cat ~/.ssh/github_actions  # 复制私钥
```

2. **添加 GitHub Secrets：**

访问：`https://github.com/你的用户名/v信/settings/secrets/actions`

添加以下 Secrets：

| 名称 | 值 |
|------|-----|
| `SERVER_HOST` | 你的服务器IP或域名 |
| `SERVER_USER` | `root` |
| `SERVER_SSH_KEY` | 上面生成的私钥内容 |
| `SLACK_WEBHOOK` | Slack Webhook URL（可选） |
| `GRAFANA_PASSWORD` | Grafana 密码 |

3. **推送代码触发 CI/CD：**

```bash
cd /root/v信

# 查看修改
git status

# 提交所有优化
git add .
git commit -m "feat: P0+P1 极致优化 - 缓存/监控/CI/CD/OSS"

# 推送到 GitHub
git push origin main
```

4. **查看 Actions 运行状态：**

访问：`https://github.com/你的用户名/v信/actions`

### 4️⃣ 配置 CDN + OSS（30 分钟，可选）

**前置准备：**
- 阿里云账号
- 已创建 OSS Bucket
- 已申请 CDN 域名并备案

**步骤：**

```bash

# 1. 安装 OSS SDK

# OSS 配置
OSS_REGION=oss-cn-hangzhou
OSS_ACCESS_KEY_ID=你的AccessKeyId
OSS_ACCESS_KEY_SECRET=你的AccessKeySecret
OSS_BUCKET=vxin-media
OSS_CDN_DOMAIN=https://cdn.dipsin.com

# 3. 修改上传路由（已有 ossUpload.js 工具）
# 编辑 src/routes/upload.js，将本地存储改为 OSS

# 5. 测试上传
curl -X POST https://dipsin.com/api/upload/avatar \
  -F "avatar=@test.jpg" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
