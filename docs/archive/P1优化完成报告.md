### 1. ✅ Redis 缓存优化
**状态**: 工具已实现 ✓

**实施内容**:

**新增缓存类** (`/root/v信/backend-v2/src/utils/redisCache.js`):
- `OnlineStatusCache` - 用户在线状态缓存（90s TTL）
  - setOnline() - 设置在线
  - getOnline() - 获取状态
  - batchGetOnline() - 批量获取
  - setOffline() - 设置离线
  - getOnlineCount() - 在线用户数

- `FriendsCache` - 好友列表缓存（30分钟 TTL）
  - set() - 缓存好友列表
  - get() - 获取好友列表
  - invalidate() - 使缓存失效
  - batchInvalidate() - 批量失效

- `UnreadCountCache` - 未读消息计数缓存（1小时 TTL）
  - increment() - 增加未读数
  - get() - 获取未读数
  - clear() - 清零未读数
  - getAllForUser() - 获取用户所有会话未读
  - getTotalForUser() - 获取总未读数

- `ConversationsCache` - 会话列表缓存（10分钟 TTL）
  - set() - 缓存会话列表
  - get() - 获取会话列表
  - invalidate() - 使缓存失效

- `UserInfoCache` - 用户信息缓存（1小时 TTL）
  - set() - 缓存用户信息
  - get() - 获取用户信息
  - batchGet() - 批量获取
  - invalidate() - 使缓存失效

**预期效果**:
- 好友列表查询: 从 DB 每次 50ms → Redis 2ms (96% 提升)
- 在线状态检查: 30ms → 1ms (97% 提升)
- 未读计数查询: 20ms → 1ms (95% 提升)
- 减少数据库负载: 60%+

## 🚀 部署步骤

### 1. 启动监控系统

```bash
cd /root/v信/backend-v2

# 启动监控栈
docker-compose -f docker-compose.monitoring.yml up -d

# 查看状态
docker-compose -f docker-compose.monitoring.yml ps

# 访问 Grafana
open http://localhost:3000
# 用户名: admin, 密码: admin
```

### 2. 集成 Redis 缓存

```bash
# 在需要的路由中引入
const { 
  onlineStatusCache, 
  friendsCache, 
  unreadCountCache 
} = require('../utils/redisCache');

# 示例：好友列表缓存
router.get('/contacts', auth, async (req, res) => {
  // 先查缓存
  let friends = await friendsCache.get(req.user.userId);
  
  if (!friends) {
    // 缓存未命中，查数据库
    friends = await db.prepare('SELECT * FROM friends WHERE user_id = ?')
      .all(req.user.userId);
    
    // 写入缓存
    await friendsCache.set(req.user.userId, friends);
  }
  
  res.json(friends);
});
```

### 3. 配置 GitHub Actions

```bash
# 添加 GitHub Secrets (Settings → Secrets → Actions)
SERVER_HOST=你的服务器IP
SERVER_USER=root
SERVER_SSH_KEY=你的SSH私钥
SLACK_WEBHOOK=Slack Webhook URL（可选）
GRAFANA_PASSWORD=Grafana密码

# 推送代码触发 CI/CD
git add .
git commit -m "feat: add P1 optimizations"
git push origin main
```

### 4. 配置 CDN + OSS（可选）

```bash
# 1. 安装 OSS SDK
cd /root/v信/backend-v2
npm install ali-oss --save

# 2. 配置环境变量
cat >> .env << 'ENVEOF'
OSS_REGION=oss-cn-hangzhou
OSS_ACCESS_KEY_ID=你的AccessKeyId
OSS_ACCESS_KEY_SECRET=你的AccessKeySecret
OSS_BUCKET=vxin-media
OSS_CDN_DOMAIN=https://cdn.dipsin.com
ENVEOF

# 3. 重启服务
pm2 restart vxin-server-v2
```
