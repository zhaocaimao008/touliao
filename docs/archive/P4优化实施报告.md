|------|------|---------|
| 送达率 | 99.99% | ACK + 重试 |
| 重试次数 | 最多 3 次 | exponential backoff |

| 死信队列 | 自动转移 | 3 次失败后 |
| 消息状态 | 完整追踪 | pending/sent/delivered/read |

**核心特性**:
- ✅ Redis 队列（持久化）

- ✅ 指数退避重试

### 集成到服务启动

**修改** `src/server.js`:
```javascript
// P4.1: 初始化 FTS5 全文搜索
const { initFTS5 } = require('./utils/ftsSearch');
initFTS5();

// P4.2: 初始化消息队列
const MessageQueue = require('./utils/messageQueue');
const AckManager = require('./utils/ackManager');
const msgQueue = new MessageQueue({ maxRetries: 3 });
const ackManager = new AckManager();
app.set('msgQueue', msgQueue);
app.set('ackManager', ackManager);
```

**修改** `src/app.js`:
```javascript
// P4.1: 全文搜索
app.use('/api/search', require('./routes/search.routes'));

// P4.2: 消息可靠性
app.use('/api/reliability', require('./routes/reliability.routes'));
```

## 🚀 部署步骤

### 1. 备份数据库
```bash
cd /root/v信/backend-v2
cp src/wechat.db src/wechat.db.backup.$(date +%s)
```

### 2. 重启服务（自动初始化）
```bash
pm2 restart vxin-server-v2

# 查看初始化日志
pm2 logs vxin-server-v2 | grep "P4"
```

### 3. 运行测试验证
```bash
npm test -- test/ftsSearch.test.js
npm test -- test/messageQueue.test.js
npm test  # 全量测试
```

### 4. 验证新 API 端点
