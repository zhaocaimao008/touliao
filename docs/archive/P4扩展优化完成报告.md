#### 使用场景
```javascript

const clientMsgId = generateUUID();

// 1. 先检查是否重复

// 2. 发送消息

// 3. 标记为已处理
await markProcessed(clientMsgId, { sentAt: Date.now() });
```

#### 性能指标

- 批量检查 100 条: < 50ms

### P4.7 网络感知重试 ⭐⭐⭐⭐⭐
**文件**: `src/utils/networkAwareRetry.js` (260 行)

#### 网络质量分级
```
📊 网络质量评级
├─ excellent (< 100ms)   → 重试 2 次，延迟 1-5s
├─ good (< 500ms)        → 重试 3 次，延迟 2-15s
├─ poor (< 2000ms)       → 重试 5 次，延迟 5-30s
└─ offline (> 2000ms)    → 重试 10 次，延迟 10-60s
```

#### 重试策略
```javascript
// 指数退避 + 抖动
delay = baseDelay × multiplier^(attempt-1) ± 随机抖动(20%)

示例:
excellent: 1s, 2s, 4s
good:      2s, 4s, 8s
poor:      5s, 7.5s, 11.25s
offline:   10s, 10s, 10s
```

#### 核心功能
- ✅ 实时网络检测 (30 秒一次)
- ✅ 自适应重试延迟
- ✅ 批量任务重试支持
- ✅ 网络质量手动设置
- ✅ 智能抖动防止雷鸣羊群效应

#### API 端点 (2 个)
```
GET    /api/optimization/network/quality       - 获取网络信息
POST   /api/optimization/network/detect        - 检测网络质量
```

#### 使用示例
```javascript
const networkAware = new NetworkAwareRetry();

// 执行带网络感知的任务
await networkAware.executeWithRetry(
  async () => {
    return await sendMessage(msg);
  },
  'sendMessage'
);
```
