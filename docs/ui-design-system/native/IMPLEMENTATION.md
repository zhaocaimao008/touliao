## 原生截图与最终复查

- Android 会话测试入口补齐 SavedStateHandle 参数，断言聊天消息和群名已实际加载，避免把空态截图当作内容页验收。
- Android 原生键盘 / 返回 / 登录表单测试通过后，采用直接 instrumentation 运行并在卸载前取回截图；此前 Gradle 自动卸载导致截图被清理，相关历史运行不计作截图交付。
- iOS 指定可用 iPhone，关闭并行测试克隆，保存 app Documents 原图、XCTest 附件和 xcresult；无 PNG 时收集任务失败，避免仅以编译成功代替图片证据。
- 二维码页面增加测试专用 PNG 返回和原生截图；正式二维码 API 不变。两端 QR 内容允许随大字号滚动。
- Android 聊天输入栏残留系统表情按钮替换为线性图标；设计包缺少的键盘、录音停止符号沿用同一网格补充，不改原始 136 SVG。
