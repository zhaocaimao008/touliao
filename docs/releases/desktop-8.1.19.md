# Windows 8.1.19 / Web 8.1.18

## 通话与界面

- 群语音开麦失败显示重试；入会、等待、媒体接通与重连分别提示。
- 异常退出与挂断统一清理连接、麦克风、摄像头及定时器。
- 增加音频输出选择、设备拔出恢复、成员音量、说话指示与通话计时。
- 群通话可最小化并继续聊天；恢复不重建音频播放器，切换布局保持通话。
- 改进九人网格、窄屏邀请、权限提示及键盘焦点处理。
- 语音录制保留实际编码类型，修复 WebM 音频本地上传被分类为视频的问题。
- 群邀请在通话结束或过期时停止提醒；TURN 探针正确释放 UDP socket。

## 发布范围

Web 与后端部署到现有生产站点。Windows 桌面端内置 Web 资源，需重新构建并通过签名更新源发布 8.1.19。

Android 和 iOS 为独立原生实现，本轮没有改动其源码或版本号，因此不触发对应发布；重新打包不会引入本轮 Web 界面变更。

## 部署修正

后端流水线使用实际 PM2 目录 `/home/ubuntu/gh-mirror/touliao/backend-v2`，静态发布与 nginx 操作使用 sudo。发布锁定触发提交，健康检查成功后记录已部署提交，供失败回退使用。

## 验证

Web 单元测试 220 项；另有真实 Chromium 双端音频、最小化聊天、设备接口回退、九人布局及释放回归。音频设备列表在自动化中受控，物理耳机/蓝牙与移动端后台来电须另作实机验收。
