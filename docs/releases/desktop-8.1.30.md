# Windows 8.1.30 — 视频下载修复

基于已发布的 Windows 8.1.29（d376c6a2），仅合入本次视频下载修复，保留既有界面、焦点管理、账号窗口及更新完成/安装失败反馈。

- 上传中打开的视频预览在发送成功后自动切换正式地址，失败重试重新创建本地预览。
- 下载按任务流式保存，显示实际进度和保存结果；失败、取消及重试都传递到主进程。
- 并发下载使用独立文件名和打开选项，同名文件独占创建，避免覆盖。
- 保留下载来源和 IPC 发送者限制，以及危险文件自动打开限制。

发布范围仅限 Windows。用户于 2026-09-23 明确要求：“不要证书，我自己用，给我出新版”。因此本次 8.1.30 自用包沿用线上渠道的无 Authenticode 发布者证书形式；保留 Ed25519 更新元数据签名、完整文件哈希、原生 Windows 安装/下载回归和线上切换备份。此授权仅对应本次版本，不修改默认生产证书门槛，不将 Ed25519 描述为 Windows 发布者签名。

构建使用 Windows runner。发布前验证安装包中的实际下载模块，Windows 安装后的下载、失败、取消、并发及同名文件保存；发布后逐字节验证更新元数据、版本化安装包、blockmap 和两个固定下载地址。原 8.1.29 保留用于回滚。
