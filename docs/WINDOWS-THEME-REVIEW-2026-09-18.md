# 投聊 Windows 字体及日间／夜间界面检查

仅调整 Windows。修正已提交到 `fix/windows-ui-20260918`，没有再发版，线上仍为 8.1.25；Android、iOS 和网站部署未改变。

[交互预览](/home/ubuntu/touliao-windows-theme-review-20260918/preview.html)可切换极光紫、微信绿、企微蓝，比较日间／夜间的聊天、外观、个人设置、通讯录、右键菜单、转发、最小窗口登录及特大字号。

检查发现并修正：

- 字体层级不一致：输入区固定 14px，聊天字号切换后输入内容未同步；部分时间与状态只有 10–11px。现在输入区跟随消息字号（12／14／16／18px），时间、发送状态、导航和主要辅助文字统一为 12px，名称和标题保留层级；半像素字号归整，时间数字对齐。字号预览同时展示中文与英文。
- Windows 字体栈统一为 Segoe UI、Microsoft YaHei UI、Microsoft YaHei。真实 Windows 字体采样确认中文实际使用 Microsoft YaHei UI；没有修改非 Windows 的字体规则。
- 夜间绿色气泡白字对比度约 1.88:1，蓝色约 3.26:1；现为更柔和的深绿／深蓝底，正文约 8.06:1／7.99:1。文字强调色与实心按钮底色分别定义，修正亮色按钮上的白字、导航选中文字、草稿、辅助时间及“已发送”状态。
- 处理旧皮肤样式覆盖 Windows 夜间配色的问题，同时统一气泡内链接、引用、文件名、文件说明、编辑标记和语音文字，改善语音播放图标的可辨识度。
- 外观设置原先混用固定黑白及分割色块，夜间出现突兀亮块；现使用同一套卡片表面、边框和选中态。右键菜单、主要操作按钮和输入焦点也跟随同一套明暗规则。
